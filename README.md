## Publication

**ECAYOLOv8n-LC: An ECA Attention Enhanced YOLOv8n-seg with Lovasz-Hinge Loss and CautiousAdamW for Electronic Component Defect Instance Segmentation**  
CISAT 2026, accepted EI conference paper. Sole author.

This work focuses on lightweight instance segmentation for industrial electronic component defect detection. The method builds on YOLOv8n-seg and integrates ECA attention, Lovasz-Hinge loss, and CautiousAdamW.

Results reported in the original experimental environment:

| Metric | Result |
| --- | ---: |
| mask mAP@0.5 | 79.28% |
| mask mAP@0.5:0.95 | 61.52% |
| Parameters | approximately 3.2M |
| Single-image inference latency | approximately 8.4 ms |
